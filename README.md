# tablero-seguros
Deploy app: Julian Alcala
Esta aplicación permite explorar una cartera de seguros de auto y estimar una prima según el perfil del asegurado.

En **Cartera**, utiliza los filtros laterales y pulsa **Aplicar filtros** para consultar indicadores y gráficas. En **Detalle**, compara los resultados por segmento y descarga la tabla.

En **Cotizador**, captura los datos del conductor y del vehículo y pulsa **Cotizar**. Verás la prima empírica basada en pólizas similares, la estimación del modelo y el precio con gastos y margen. La gráfica muestra qué factores aumentan o reducen la prima estimada.

Si cambias el perfil, vuelve a pulsar **Cotizar** para actualizar los resultados.
